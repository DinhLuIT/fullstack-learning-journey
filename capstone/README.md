| Phiên bản | Giai đoạn | Thay đổi chính | Tag |
| --- | --- | --- | --- |
| v1 | 2 | REST API bằng Java thuần + JDBC | `v1-raw-java` |
| v2 | 2 | Spring Boot + JPA, JWT, Redis, test | `v2-spring` |
| v3 | 3 | Frontend vanilla JS, sau đó React + TypeScript | `v3-frontend` |
| v4 | 4 | Trợ lý AI: RAG và tool calling | `v4-ai` |
